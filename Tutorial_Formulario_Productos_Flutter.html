Flutter · App de inventario · Parte 1

Formulario de productos con validaciones

Vas a construir la primera parte de una aplicación de inventario: un formulario para escribir el nombre, el precio y la cantidad de un producto, que valida la información antes de continuar.

12 pasos cortos 2 archivos Dart Desde cero
ConstruirUna pantalla con tres campos y un botón.
LeerLo que escribe el usuario en cada campo.
ValidarQue los datos cumplan reglas antes de continuar.

En esta primera parte todavía no guardaremos productos en una lista. Primero aprenderemos a construir el formulario y comprobar sus datos. El teléfono de la derecha muestra cómo va tu app en el paso que estás leyendo, y puedes usarlo.

PASO 01

Crear el proyecto

Abre Visual Studio Code y sigue estos pasos:

  1. Presiona Ctrl + Shift + P.
  2. Busca Flutter: New Project.
  3. Selecciona Application.
  4. Elige la carpeta donde guardarás el proyecto.
  5. Escribe el nombre inventario_productos.

Dentro de la carpeta lib, crea una carpeta llamada screens. Allí crea el archivo pantalla_productos.dart. La estructura quedará así:

lib/
├── main.dartinicia la aplicación
└── screens/
└── pantalla_productos.dartla pantalla que vamos a construir
¿Por qué usamos dos archivos?

Separar los archivos desde el principio nos ayuda a mantener el código organizado: uno arranca la app y el otro contiene la pantalla.

Paso 5: Leer lo que se escribe →
PASO 05pantalla_productos.dart

Aprender a leer lo que escribe el usuario

Para validar los datos, primero debemos poder acceder a ellos. Flutter proporciona una herramienta llamada TextEditingController.

Dentro de _PantallaProductosState, antes del método build(), agrega:

dentro de _PantallaProductosState
final nombreController = TextEditingController();final precioController = TextEditingController();final cantidadController = TextEditingController();

Estos tres controladores nos permiten leer el contenido de cada campo. Por ejemplo, si el usuario escribe Teclado, podemos obtenerlo así:

lectura
nombreController.text

Si escribe 85000 en el campo del precio:

lectura
precioController.text

El resultado es texto, incluso si contiene números: "85000", no 85000. Más adelante validaremos ese texto y comprobaremos si representa un número válido.

Conectar los controladores

Agrega la propiedad controller a cada campo. Por ejemplo, el campo del nombre debe quedar así:

campo del nombre
TextField(  controller: nombreController,  decoration: const InputDecoration(    labelText: 'Nombre del producto',    border: OutlineInputBorder(),  ),),

Haz lo mismo con los otros dos campos:

  • Precio: controller: precioController
  • Cantidad: controller: cantidadController

También debemos liberar los controladores cuando la pantalla se cierre. Agrega este método dentro de _PantallaProductosState, fuera de build():

dentro de _PantallaProductosState
@overridevoid dispose() {  nombreController.dispose();  precioController.dispose();  cantidadController.dispose();​  super.dispose();}
Comprueba tu avance

Los tres campos deben seguir funcionando y ahora cada uno tiene un controlador que permite leer su contenido.

Paso 6: Qué es una validación →
PASO 06pantalla_productos.dart

Entender qué es una validación

Una validación es una regla que comprueba si la información ingresada cumple una condición. En nuestro formulario aplicaremos estas reglas:

CampoReglaMensaje si falla
NombreNo puede estar vacío.Escribe el nombre del producto
PrecioDebe ser un número mayor que cero.Escribe un precio válido mayor que cero
CantidadDebe ser un número entero mayor que cero.Escribe una cantidad entera mayor que cero

Para lograrlo, vamos a aprender dos elementos nuevos: Form y TextFormField.

FormAgrupa varios campos y permite validarlos todos desde un mismo lugar. Para identificarlo necesitamos una llave.
TextFormFieldEs un campo de texto que incorpora la propiedad validator, donde escribimos la regla de validación.

Dentro de _PantallaProductosState, agrega la llave del formulario:

dentro de _PantallaProductosState
final formularioKey = GlobalKey<FormState>();

La llave nos permitirá pedirle al formulario que compruebe sus campos cuando se pulse el botón. Y como necesitamos validator, en los próximos pasos vamos a reemplazar los TextField por TextFormField.

Paso 7: Validar el nombre →
PASO 07pantalla_productos.dart

Validar el nombre del producto

Reemplaza el campo del nombre por este código:

campo del nombre
TextFormField(  controller: nombreController,  decoration: const InputDecoration(    labelText: 'Nombre del producto',    border: OutlineInputBorder(),  ),  validator: (valor) {    if (valor == null || valor.trim().isEmpty) {      return 'Escribe el nombre del producto';    }​    return null;  },),

Lo nuevo: TextFormField y la función validator.

Explicación sencilla

La función validator recibe el valor escrito en el campo.

la condición
if (valor == null || valor.trim().isEmpty) {  return 'Escribe el nombre del producto';}

Esta condición comprueba si el campo está vacío o contiene únicamente espacios (trim() los quita antes de comprobar).

Devuelve un texto → hay un errorreturn 'Escribe el nombre del producto';Flutter muestra ese texto debajo del campo, en rojo.
Devuelve null → el campo es válidoreturn null;Si tiene un nombre, la función llega hasta aquí.
Regla para recordar

En un validador, devolver un texto significa que hay un error; devolver null significa que el campo es válido.

Paso 8: Validar el precio →
PASO 08pantalla_productos.dart

Validar el precio

Ahora reemplaza el campo del precio por este:

campo del precio
TextFormField(  controller: precioController,  keyboardType: const TextInputType.numberWithOptions(    decimal: true,  ),  decoration: const InputDecoration(    labelText: 'Precio',    border: OutlineInputBorder(),  ),  validator: (valor) {    if (valor == null || valor.trim().isEmpty) {      return 'Escribe el precio';    }​    final precio = double.tryParse(      valor.trim().replaceAll(',', '.'),    );​    if (precio == null || !precio.isFinite || precio <= 0) {      return 'Escribe un precio válido mayor que cero';    }​    return null;  },),

¿Qué conceptos nuevos aparecen?

keyboardTypeSugiere un teclado numérico. Sin embargo, no garantiza que el usuario ingrese un número válido.
double.tryParse()Intenta convertir el texto a un número decimal. Si no puede, devuelve null.
replaceAll(',', '.')Cambia la coma por punto, para que 85,5 se lea como 85.5.
precio <= 0Impide aceptar precios iguales a cero o negativos.

De esta manera, el precio debe ser numérico, finito y mayor que cero. Toca un ejemplo para verlo paso a paso en el laboratorio del paso 9.

Paso 10: Agrupar en Form →
PASO 10pantalla_productos.dart

Agrupar los campos dentro de Form

Para que Flutter pueda validar los tres campos juntos, debemos envolver el Column con un Form. En el método build(), cambia esta parte:

antes
body: Padding(  padding: const EdgeInsets.all(16),  child: Column(    children: [      // Aquí están los campos y el botón.    ],  ),),

Por esta estructura:

después
body: Padding(  padding: const EdgeInsets.all(16),  child: Form(    key: formularioKey,    child: Column(      children: [        // Aquí están los tres TextFormField.        // Aquí está el botón.      ],    ),  ),),

No tienes que volver a escribir los campos: simplemente deben quedar dentro del Column, que ahora está dentro de Form. La propiedad:

dentro de Form
key: formularioKey,

conecta el formulario con la llave que creamos en el paso 6.

Truco de VS Code: pon el cursor sobre Column, pulsa Ctrl + . y elige Wrap with widget…. Luego cambia widget por Form y agrega la key.

Paso 11: Conectar el botón →
PASO 11pantalla_productos.dart

Hacer que el botón valide los campos

Primero, agrega este método dentro de _PantallaProductosState, antes de build():

dentro de _PantallaProductosState, antes de build()
void validarFormulario() {  if (formularioKey.currentState!.validate()) {    ScaffoldMessenger.of(context).showSnackBar(      const SnackBar(        content: Text('Todos los campos son válidos'),      ),    );  }}

Después, conecta el botón con el método:

el botón
ElevatedButton(  onPressed: validarFormulario,  child: const Text('Validar formulario'),),

¿Qué sucede cuando pulsamos el botón?

La instrucción más importante es:

la instrucción clave
formularioKey.currentState!.validate()
1 · onPressedEl usuario pulsa «Validar formulario».
2 · validarFormulario()Se pide al formulario, mediante su llave, que se valide.
3 · validate()Flutter ejecuta el validator de cada campo del formulario.
Algún campo es incorrectoDevuelve false y muestra los mensajes de error debajo de los campos.
Todos los campos son correctosDevuelve true y aparece el SnackBar «Todos los campos son válidos».

Todavía no estamos guardando productos. Por ahora solo comprobamos que los datos sean válidos. Pruébalo ya en el teléfono: deja un campo vacío y pulsa el botón.

RESUMEN

¿Qué aprendiste hasta aquí?

Ya sabes construir una pantalla, crear campos de texto, leer lo que escribe el usuario y validar un formulario. Los cuatro conceptos fundamentales son:

TextEditingControllerPermite leer el texto de los campos.
FormAgrupa los campos que se validarán.
validatorDefine las reglas de cada campo.
validate()Ejecuta las reglas y determina si el formulario es válido.
